## Fuentes académicas: no confundir propuesta con rúbrica

- [Especificación original de FixIt](references/FixIt_Project_Specification.pdf) (21 pp.): propuesta de mantenimiento general/IA atribuida por el usuario a **Valeria**, creada con la cuenta de Yaderling que figura en portada. No obliga a implementar cada funcionalidad de ese alcance anterior.
- [Adaptación a Cloud y Software Engineering II](references/FixIt_Adapting_Cloud_and_Software_Engineering_II_2026-11-10.pdf) (23 pp.): alternativa con dos VPC, página S3 y dos contextos DDD; **no está ratificada por los tres profesores**.
- [Requisito Contract-First COP3851 de Félix](references/COP3851_Capstone_2026-11-11.md): OpenAPI y 3NF/FK/migración previamente commiteados y validados antes de controllers, reglas de agentes en raíz, seguridad, red-team, dependency RFC y defensa en vivo. La transcripción está preservada; PDF original de una página no reside en este checkout.
- Según el usuario, **Marvin aprobó orientar Cloud a una VPC y una EC2 y usar S3 para versionado de releases**. Es una confirmación oral, no evidencia de AWS provisionada ni reemplaza fechas o rúbrica escrita.

## Decisiones ya seleccionadas

- Auth/Tickets/Chat como **tres servicios candidatos**; sesiones opacas y Argon2id; PostgreSQL por esquemas `auth`/`tickets`, MongoDB para chat, NATS JetStream candidato. **El detalle requiere revisión técnica del equipo y pruebas.**
- FixIt **single-tenant, solo Keiser University LAC**; sin `tenant_id`, con autorización backend por reporter/asignado/Admin.
- AWS: DigitalPlat + Cloudflare Tunnel; EC2 Spot para pruebas con opción On-Demand de emergencia; S3 privado Versioning y backups persistentes; techo **US$120 de consumo total con créditos elegibles disponibles**. Sin despliegue autorizado.
