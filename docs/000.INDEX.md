# FixIt — índice canónico

**Estado (18 nov):** FixIt single-tenant para Keiser LAC. `dev` contiene **documentación y contratos, no código de aplicación**. OpenAPI 3.1.1 (24 rutas/28 operaciones) fue validada con 5 advertencias no bloqueantes; Prisma 7.10.1 aplicó la migración SQL en PostgreSQL 17 temporal y la comparación no detectó diferencias representables en Prisma. Los `CHECK`/índices especiales requieren revisión SQL independiente. El prototipo Auth/tests permanece en `prototype/auth-g4`; ningún gate completo PASS. **Secuencia de desarrollo elegida 18 nov: servicios/JetStream locales en contenedores; RDS PostgreSQL y Atlas como bases remotas cuando sean accesibles y estén autorizadas, con fallback local. El hosting final EC2/Compose vs Fargate sigue por decidir.**

La transcripción está preservada; PDF original de una página no reside en este checkout.
- Según el usuario, **Marvin aprobó orientar Cloud a una VPC y una EC2 y usar S3 para versionado de releases**. Es una confirmación oral, no evidencia de AWS provisionada ni reemplaza fechas o rúbrica escrita.

## Decisiones ya seleccionadas

- Auth/Tickets/Chat como **tres servicios candidatos**; sesiones opacas y Argon2id; PostgreSQL por esquemas `auth`/`tickets`, MongoDB para chat, NATS JetStream candidato. **El detalle requiere revisión técnica del equipo y pruebas.**
- FixIt **single-tenant, solo Keiser University LAC**; sin `tenant_id`, con autorización backend por reporter/asignado/Admin.
- **Cloud:** la opción EC2 Spot/Compose con Tunnel y S3 era el baseline seleccionado para estudio; desde el 17 nov se evalúa **ECS Fargate + RDS + Atlas** por recomendación transmitida del profesor. **Ninguna topología definitiva aceptada**; S3 Versioning de releases y backups, límite de planificación **US$120 brutos acumulados sujeto a créditos elegibles** y autorización previa a todo despliegue continúan vigentes.
