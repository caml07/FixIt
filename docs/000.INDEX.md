## Acuerdos confirmados vs. hipótesis

**Seleccionado por usuario:** FixIt es **Help Desk single-tenant para Keiser University LAC (piloto academico)**, sin `tenant_id`; autorizacion por reporter/asignado/Admin. **Validado a nivel conceptual con equipo:** IT Help Desk y la **division Auth/Tickets/Chat**. PostgreSQL compartida en `auth`/`tickets`, MongoDB para mensajes, REST de permisos y NATS JetStream con outbox siguen en revision tecnica. Sesiones opacas, seeder del primer Admin y **Argon2id** para contrasenas elegidos por el usuario el 15 nov, pendientes de pruebas. Ver [010.G1](010.G1-Contracts.md), [ADR-005](adr/ADR-005-three-services-opaque-sessions.md), [006.Decisions](006.Decisions.md) y [CONTEXT](../CONTEXT.md).

**Cloud comunicado por el usuario:** Marvin acepta **una VPC y una EC2** y espera S3; Valeria apoya la direccion pero destaca el **riesgo de costos**. El usuario eligio **DigitalPlat + Cloudflare DNS + Tunnel nombrado** para publicacion publica, sin registrar nada, con el usuario titular y Valeria delegada si se permite. **US$120 de costo AWS acumulado para todo FixIt**, cubierto solo por creditos comprobados, no gasto personal. **S3 privado con Versioning para releases confirmado por Marvin segun el usuario**; **EC2 Spot `persistent` EBS-backed con `stop` seleccionada para pruebas puntuales, no 24/7**, contingencia **On-Demand como nueva instancia temporal** cuando Spot no este disponible; backups cifrados PG/Mongo conservados en S3, sin caducidad automatica. Faltan saldo/plan, capacidad, salida EC2 y fechas. Cloud corresponde a caml07 y Valeria; Rina participa en Web II y no cursa Cloud. **No se desplego ni autorizo gasto**.

## Reglas de mantenimiento

- Cambios de alcance: editar 001 y marcar el ADR relacionado.
- Comportamiento: **002**; diseño vigente y contratos conceptuales: **010**; AWS/precios: **004**; ejecución: **005**. `003` es alternativa historica.
- Cada FR/NFR tiene ID estable y prueba prevista; no renumerar IDs existentes.
- Cada ADR describe **estado** (proposed/accepted/superseded) y alternativa descartada; no convertir un borrador en acuerdo sin confirmación.
- No crear implementación, IAM, VPC, buckets ni cuentas por el hecho de estar descritos aquí.
- GitHub es la fuente de verdad del codigo y documentacion. **S3 privado con Versioning de releases fue confirmado como requisito de Marvin segun el usuario el 15 nov**; no es hosting web ni sustituye Git o backups de DB.
- Documentos sin código ni infraestructura se etiquetan **diseño / no verificado**.
