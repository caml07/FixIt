## 1.0 Course Overview & Architectural Mandate

Secure full-stack web application for complex community operations. **Database
schemas (3NF) and OpenAPI specifications must be committed before AI agents
generate controller endpoints.** Agents may not generate endpoints without a
pre-existing OpenAPI contract. All database queries use bound parameters to
eliminate injection vectors.

## 2.0 Technical Requirements & Stack Standards

- Relational database: PostgreSQL or SQLite, normalized to **3NF**,
  **explicit foreign keys**.
- RESTful HTTP endpoints, parameterized queries, middleware pipeline.
- Secure **Session/JWT** handling (either permitted by the text);
  **Argon2/BCrypt** password hashing; **HttpOnly** cookies.

## 3.0 Context Architecture & System Constitution

A root **`CLAUDE.md` or `GEMINI.md`** must enforce:

1. Endpoint signatures strictly follow **`docs/openapi.json`**.
2. Row-level access control; PDF illustrates `WHERE tenant_id = current_user`.
3. No dynamic SQL; use parameterized queries or ORM bindings.
4. Auth cookies **`HttpOnly; Secure; SameSite=Strict`**.

## 4.0 Adversarial AI Red-Team Security Audit

Before submission, an AI Red-Team Agent attempts: **BOLA/IDOR harvesting,
SQL/NoSQL injection, CORS credential leaks, rate-limit bypasses** against the
running API. Mandatory row-level authorization on modification operations,
explicit CORS domain lock (**not wildcard `*`**) and security headers.

## 5.0 Dependency Governance (RFC Protocol)

AI suggestions for backend npm/NuGet packages require **[DEPENDENCY RFC]**:
CVE auditing (with `npm audit`) and justification against hand-rolled
middleware.
